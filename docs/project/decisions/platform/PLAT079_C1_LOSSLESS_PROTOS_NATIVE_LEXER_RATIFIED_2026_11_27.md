## Selected lexer contract

`Lexer.lex(source, recover: false, maxScalars: 262144, maxPieces: 262145)`

- source: genuine semantic String; recover: genuine Boolean; maxScalars: nonnegative Integer; maxPieces: Integer >= 1. No coercion. Bounds inclusive; maxPieces includes EOF, reserve capacity before admitting pieces. Invalid arguments signal fresh ordinary Error. Bound failure signals fresh package-local LexerLimitError(limit, maximum); no partial successful result. Limits are resource policy, not lexical grammar restrictions.
- Return fresh ordinary object {pieces, diagnostics}, with fresh independent ordinary Arrays and records. Private Unicode data immutable and Actor-local under existing rules; no new transfer family, shared mutable state or cross-Context sharing.
- Each piece: {kind, start, end, rawText, lexeme, escapeSpans}. kind is String, start/end scalar Integer offsets, zero-based half-open. rawText is exact source substring, never normalized. lexeme is raw spelling for ordinary tokens including NUMBER, decoded value for STRING, LF for NEWLINE, empty String for EOF, null for trivia and ERROR. escapeSpans is an Array of absolute half-open source spans of valid escapes within a successfully recognized STRING, empty otherwise. No parser semantics or numeric conversion.
- Exact partition: ordered, no gaps/overlaps, every non-EOF piece has positive length, final EOF once at [N,N), empty rawText; concatenation of rawText equals input, including mixed CR/LF/CRLF, NUL and U+FEFF. Empty input yields EOF only. Source offsets are scalar positions, not UTF-16, byte, grapheme or display-column positions. Java differential adapter converts UTF-16 explicitly. No synthetic tokens or implicit normalization. Input domain excludes isolated host surrogate code units because Core String excludes them.
- Token kinds are the Java TokenType names at baseline: IDENTIFIER, NUMBER, STRING, THIS, CONTEXT, NULL, TRUE, FALSE, SUPER, LPAREN, RPAREN, LBRACE, RBRACE, LBRACKET, RBRACKET, DOT, COMMA, COLON, SEMICOLON, EQUALS, FAT_ARROW, PLUS, MINUS, STAR, SLASH, PERCENT, BANG, LESS, LESS_EQUAL, GREATER, GREATER_EQUAL, DOUBLE_EQUALS, TRIPLE_EQUALS, NOT_EQUALS, NOT_EQUALS_2, AND, OR, AMPERSAND, PIPE, TILDE, SHIFT_LEFT, SHIFT_RIGHT, ELLIPSIS, CARET, NEWLINE, EOF. Additional piece kinds HORIZONTAL_WHITESPACE, LINE_COMMENT, BLOCK_COMMENT, ERROR are tool representation only, not grammar tokens. Parser projection omits trivia; invalid recovery pieces never masquerade as valid parser tokens.
- Normative grammar determines recognition: Unicode 17 XID and NFC (reject not normalize); exact six reserved words, contextual words remain identifiers even for match/if/for/while/until/return. Dedicated reserved tokens remain such after DOT. Exact ASCII digit/radix/separator/exponent and malformed numeric commitment; no numeric value conversion. Maximal symbolic run before classification; comments recognized at lexical boundaries, no retroactive splitting invalid operator runs. Ellipsis consumes three dots. SPACE/TAB only horizontal whitespace, LF/CR/CRLF one NEWLINE except inside block comments or strings; line comment leaves newline, block comments non-nesting; no implicit semicolons. Single/double/triple strings use exact escapes and scalar validation, triple quote runs, closing-delimiter indentation and raw newline preservation. Lexical vs syntactic validity remains distinct.

### Failure and recovery

One scanner recognition core, two policies. Strict (default) signals a fresh ordinary package-local LexicalError(code,start,end) on first lexical failure and produces no partial result. On success diagnostics is empty. Recovery emits a single ERROR piece and corresponding diagnostic {code,start,end} for each invalid region, continues deterministically, preserves all text and terminates. Invalid strings never emit valid STRING pieces.

Region policies: unknown scalar consumes one; non-NFC identifier and invalid symbolic spelling consume full attempted run; invalid number consumes malformed attempted numeric/identifier continuation without unrelated punctuation (unsupported radix decimal fraction consumes attempted fraction); ordinary invalid String stops at unescaped closing delimiter or before logical newline/EOF; triple invalid String consumes through unescaped triple close or EOF; unterminated block comment to EOF. Same recognition and region in strict and recover; first-error diagnosis, no zero-length recovery. Diagnostic codes: UNEXPECTED_SCALAR, NON_NFC_IDENTIFIER, INVALID_NUMERIC_LITERAL, INVALID_SYMBOLIC_OPERATOR, INVALID_STRING_ESCAPE, UNTERMINATED_STRING, STRING_NEWLINE, INVALID_TRIPLE_INDENTATION, UNTERMINATED_BLOCK_COMMENT. Ordinary runtime failures/cancellation propagate unchanged; do not catch indiscriminately or convert internal defects to lexical errors. No new Core error prototypes or semantics. Test exact boundaries, deterministic diagnostic precedence and argument/limit failures; if normative ambiguity or materially new observable contract is discovered, return to owner instead of silently selecting a new rule.

## Unicode and implementation boundaries

Use the existing tools/generate_unicode17_data.py output as one data authority: ordinary generated guest data carrier representing identical unicode17.bin bytes, encoded in bounded Base64url chunks and decoded via existing std:text/base64url, with Unicode License V3 notice and reproducibility/equality checks. No manually maintained second data table, private regex Unicode facility, host Unicode version, FFI or new Java. Private data initialized under ordinary module rules; no runtime I/O. NFC uses exact Unicode 17 canonical decomposition (including algorithmic Hangul), stable canonical ordering within starter-delimited segments, composition/blocking and comparison with original. ASCII fast path; avoid copying quadratic insertion ordering; existing stable std:collections/array.sort is a candidate for out-of-order runs. MAYBE quick-check is not YES; defer optimization until evidence. Do not normalize the input. Verify official XID and normalization data.

One UTF-8 encoding of source, private byte/scalar cursor; reuse patterns in std:regex rather than adding Java. No repeated nonconstant String indexing or repeated whole-array concatenations. Core Array has fixed length: bounded private chunk accumulation and final materialization or balanced composition. When decoding a fragment beginning with U+FEFF, preserve it using existing decoder contract (synthetic leading BOM consumed instead of original); test raw and decoded text. No encoding changes. Internal representations may be optimized without changing the selected result; any unavoidable Java production mechanism requires a new gate and exact verified equivalent in GraalPy or another Truffle language.

## Highlight contract

`Highlight.runs(source, maxScalars: 262144, maxPieces: 262145)` calls recovery recognition once. Returns ordinary {runs, diagnostics}, runs containing {role,start,end,text}, all scalar half-open positions, no EOF run, positive-length ordered exact source partition. Adjacent equal roles may merge; no text change. Roles: plain (identifier/whitespace/newline), comment, string, escape (absolute valid STRING escape spans), number, languageVariable (THIS/CONTEXT), control (SUPER), literal (TRUE/FALSE/NULL), operator (symbolic tokens and colon), punctuation (structural delimiters/separators), invalid (ERROR). Presentation-only reserved name directly adjacent to preceding DOT may be plain for legacy compatibility; lexical kind unchanged. Contextual words stay plain. No HTML/CSS/ANSI/theme/eval in lexer or classifier. No speculative syntax classification.
