## Ratified public module and operation list

Keep every existing `std:collections/Array`, `Set`, `IdentitySet`, `Range` operation and their current published semantics. Add to **`std:collections/Array` only**:

| Group | Approved entrypoints | Ratified effect/result |
|---|---|---|
| Stable sort convenience | `sort(array)` | The same existing stable, shallow, fresh-Array sort with default ordinary `(left,right)=>left<right` applied **only when `less` omitted**. Explicit `sort(array,less)` unchanged. Explicit `null` is not omission. No new String ordering, global comparable, coercion or total NaN order; `parallelSort` unchanged. |
| Positional copy/edit | `append(array,value)`, `concat(left,right)`, `slice(array,start,end)`, `insertAt(array,index,value)`, `removeAt(array,index)`, `reverse(array)` | Shallow, fresh **open** standard Array results; original Array's indexed state unchanged. `concat` concatenates exactly one level; `append` and `insertAt` insert the supplied object as **one** element, even if it is itself an Array. `slice` is `[start,end)` strictly; `insertAt` admits `index==length`, `removeAt` requires an existing index. Reverse is non-mutating. |
| Search and predicates | `find(array,predicate)`, `contains(array,value)`, `any(array,predicate)`, `all(array,predicate)` | `find` returns first **snapshotted original element** satisfying predicate, else `null` (matched `null` remains ambiguous: use existing `findIndex`). `contains` uses ordered scan with `element == sought`, not Set hashing or identity. `any` short-circuits at first true and answers false for empty; `all` short-circuits at first false and answers true for empty; strict canonical Boolean predicate validation and `InvalidPredicateResult`. |
| Transform/combination | `flatMap(array,transform)`, `zip(left,right)`, `partition(array,predicate)`, `distinct(array)` | `flatMap`: invoke mapper once per snapshot element in source order; each returned chunk **must be a standard Array**, whose shallow contents are captured **immediately** on return; flatten **one** level. `zip`: truncate to shorter Array and return fresh open Array of fresh two-element Arrays, no padding. `partition`: one predicate invocation per input and fresh outer `[matches,rejects]` with stable fresh bucket Arrays, including empty. `distinct`: preserve first occurrence/order and original element references using existing **ordinary Set/Map `hash + ==` membership**, not `===`, a custom comparator, or merely adjacent dedup. |
| Prefix/suffix | `take(array,count)`, `drop(array,count)` | Semantic nonnegative Integer count; **saturate** at Array length (counts larger than length do not signal); produce fresh open shallow Arrays, not views. No negative-from-end interpretation or numeric coercion. |

These add **sixteen** new functions plus one existing function's optional default comparator. No new Core Array selectors, mutable growth, holes, negative indexing, lazy Sequence/Iterator/Stream, Range value, collection hierarchy, public builder, equality strategy or special actor transfer category. Existing `sort` and `parallelSort` comparator invocation and strict-result contract remain except specifically for omission of `sort`'s optional comparator.

## Common explicit contract

All indexed collection inputs must be real standard Arrays owning indexed state (including descendant-factory arrays), not lookalike delegate-only objects. Source Arrays may be open, closed or frozen; producing a new Array does not mutate or open the source. Fresh Array output is standard base-factory open indexed state with independent Array identity/storage; nested elements preserve exact original references and may be shared. An empty/full/no-op slice, take, drop, etc. **still creates a distinct Array**.

Use canonical Protos Array indexed/spread shallow snapshots: callback-driven operations capture source content before callback side effects, invoke callbacks in ascending order with **one** element parameter, and do not run callbacks twice. `find` must not call `findIndex` then reread a possibly modified source. `flatMap` must snapshot **each mapper result on return** to protect against a reused and subsequently modified chunk Array. `partition` and `distinct` remember pass-one membership decisions so no predicate or user-defined equality/hash is inadvertently re-executed in the output-fill pass.

For `slice/insertAt/removeAt`, indexes are semantic unbounded Integers, validated mathematically, no host conversion/wrap or clamping. `slice`: `0<=start<=end<=n`. `insertAt`: `0<=index<=n`. `removeAt`: `0<=index<n`. `take/drop`: count>=0 with `min(count,n)`. Wrong receiver/index type/range signals normal Error, without changing source. `any/all/partition/find` use strict canonical `true` or `false`, otherwise `InvalidPredicateResult`; no truthiness, hidden Boolean conversion, or extra callback parameters. `contains` uses normal `==` with left operand being the scanned element, allowing ordinary user-defined equality/effects and error propagation. `distinct` deliberately chooses Set semantics and its hash-coherence requirements, including existing hash/equality suspension and mutable-key risks. The other methods do not gain implicit Set/hash semantics.

Preserve Protos ordinary polymorphic invocation, flexible argument binding (extra supplied args are ignored unless an owning contract explicitly enforces a limit), ordinary error and non-local return propagation, callback effects and suspension, Actor isolation and isolated-P transfer. No hidden new Task, Actor, scheduler, shared mutable singleton, JVM bridge or native-image requirement. Empty collections do not inspect callback callability where existing array-library contracts avoid it. No unreachable partial result becomes public when an operation signals.

## Selected implementation direction and alternatives rejected

**Source-first — owner-approved:** implement using ordinary Protos operations already supported in `protos/lib/collections/Array.protos` and existing standard helpers, not host Java or runtime facilities. Direct one-shot `Array(...)` and shift-in-result for `append/concat/insertAt/reverse`. For variable-length outputs, compute output size once, allocate a correctly sized fresh base Array using geometric recursive **doubling of `Array(...half,...half)`** and fill positions once. This is already used by the source-level `sized/materialize` helpers in `protos/lib/semver/SemVer.protos`; it needs no Array length constructor or builder API. `flatMap` stages each shallow snapshot chunk, `partition` caches strict Boolean decisions, `distinct` caches first-occurrence membership flags; then allocate/fill known output counts linearly. Avoid accidentally exporting private helper names; keep the module public surface explicit.

Algorithms' asymptotic reasoning should not be misrepresented as executed benchmarks. One result's fill can be linear, while repeated fresh `append` calls naturally copy a growing sequence repeatedly. The current `Array(...source)` snapshot can still cost O(n) when slicing a tiny range from an enormous Array. Do not claim an O(k) tiny-slice guarantee or authorize a generalized Java builder from the existence of the private CLI builder. Any such optimization would need separate justified architectural approval, within ordinary governance.

**Deliberate alternative rejections:** `distinct` by IdentitySet is not normal equality, `flatMap` accepting arbitrary scalars or recursive flattening adds coercion/semantics, strict equal-length `zip` adds surprise for ordinary composition, `partition` as chunking is a different function, strict oversized `take/drop` is less useful than saturating, and a general `Comparable` protocol for `sort` would expand Core far beyond the approved convenience. Default `sort` inherits numeric NaN unorderability from `<`: paired false comparisons are stable ties in the current implementation; the default makes no guarantee of a total order on arbitrary mixed objects.

No previously ratified invariant is reopened by this selected Standard Library-only contract.
