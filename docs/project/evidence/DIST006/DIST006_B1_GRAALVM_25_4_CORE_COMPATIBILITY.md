The already-existing tests were sufficient to establish the migration
compatibility properties required by B1:

- exact optimizing runtime selection with no fallback;
- successful generated Bytecode DSL compilation/execution under 25.4;
- exact source identities and source sections;
- statement/expression/call tag projection;
- stable caller/callee continuation locations;
- debugger scopes derived from Protos activation state;
- no exposure of Bytecode implementation temporaries;
- real DAP breakpoint/source/scope/value/step/continue behavior;
- stable Protos-owned readiness protocol.

No observed source/debug defect required a workaround for the upstream 25.4
compressed-source behavior.
