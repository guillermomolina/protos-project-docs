## Verified external mechanisms and limits

- [GraalPy `ByteSequenceStorage`](https://github.com/oracle/graalpython/blob/main/graalpython/com.oracle.graal.python/src/com/oracle/graal/python/runtime/sequence/storage/ByteSequenceStorage.java): `byte[]`, `getIntItemNormalized` unsigned, `getCopyOfInternalArrayObject` defensive copy, `@ExportLibrary(PythonBufferAccessLibrary.class)`. Python buffer exports are **not** part of the approved Protos public model.
- [GraalPy `PList`](https://github.com/oracle/graalpython/blob/main/graalpython/com.oracle.graal.python/src/com/oracle/graal/python/builtins/objects/list/PList.java): `SequenceStorageNodes.SetItemScalarGeneralizingNode`, replacement backing after incompatible assignment. See [`SequenceStorage`](https://github.com/oracle/graalpython/blob/main/graalpython/com.oracle.graal.python/src/com/oracle/graal/python/runtime/sequence/storage/SequenceStorage.java).
- [TruffleRuby `ArrayStoreLibrary`](https://github.com/truffleruby/truffleruby/blob/main/src/main/java/org/truffleruby/core/array/library/ArrayStoreLibrary.java): `@GenerateLibrary` and `@DefaultExport`; [`LongArrayStore`](https://github.com/truffleruby/truffleruby/blob/main/src/main/java/org/truffleruby/core/array/library/LongArrayStore.java), [`DoubleArrayStore`](https://github.com/truffleruby/truffleruby/blob/main/src/main/java/org/truffleruby/core/array/library/DoubleArrayStore.java), [`ObjectArrayStore`](https://github.com/truffleruby/truffleruby/blob/main/src/main/java/org/truffleruby/core/array/library/ObjectArrayStore.java) export `acceptsValue`, `copyContents` and primitives. This is a precedent, not a requirement to create the same number of Java classes in Protos.
- [GraalJS `AbstractIntArray`](https://github.com/oracle/graaljs/blob/17b0642d3254ec43b1b109bfb2d86a6ff2ea5151/graal-js/src/com.oracle.truffle.js/src/com/oracle/truffle/js/runtime/array/dyn/AbstractIntArray.java) / [`AbstractDoubleArray`](https://github.com/oracle/graaljs/blob/17b0642d3254ec43b1b109bfb2d86a6ff2ea5151/graal-js/src/com.oracle.truffle.js/src/com/oracle/truffle/js/runtime/array/dyn/AbstractDoubleArray.java): primitive-to-object generalization; JavaScript holes and sparse semantics are not Protos.
- [FastR `RDoubleArrayVectorData`](https://github.com/oracle/fastr/blob/f9d9199e51b371f076b19456933ee395d28360bf/com.oracle.truffle.r.runtime/src/com/oracle/truffle/r/runtime/data/RDoubleArrayVectorData.java) and [`RIntArrayVectorData`](https://github.com/oracle/fastr/blob/f9d9199e51b371f076b19456933ee395d28360bf/com.oracle.truffle.r.runtime/src/com/oracle/truffle/r/runtime/data/RIntArrayVectorData.java): `@ExportLibrary(VectorDataLibrary.class)`, typed backing, explicit copies. FastR's `int[]` type domain does not define Protos's signed-64 SmallInteger type.
- [GraalPy `PString`](https://github.com/oracle/graalpython/blob/main/graalpython/com.oracle.graal.python/src/com/oracle/graal/python/builtins/objects/str/PString.java) uses `TruffleString` and `CodePointAtIndexUTF32Node`; not itself proof of a current Protos String defect.

## Governing Protos and decision constraints

- [`VALUES_AND_COLLECTIONS.md`](https://github.com/guillermomolina/protos/blob/89028494587d4d22309a5c048e37da3518170b18/spec/semantics/VALUES_AND_COLLECTIONS.md) §D214 accepts **only genuine Numbers** in Vector/Matrix; Boolean cannot enter numeric backing. The Bytes contract requires unsigned Integer 0..255, independent open identity for standard producers, and exact argument return for `add`/`atPut`.
- [`PLAT056`](../../decisions/platform/PLAT056_PRIMITIVE_FIRST_NUMERIC_GUEST_OBJECT_ARCHITECTURE.md) ratified primitive-first signed-64/Float carriers and rich values; [`PLAT068`](../../decisions/platform/PLAT068_R2_FLOAT_ADAPTIVE_MATRIX.md) ratified Matrix R2-Float **only**. Do not silently extend the latter to Vector/long.
- [`AUD023`](../../work/AUD023/AUD023_COLLECTION_PROTOCOL_COHERENCE_AUDIT.md) ratified public-collection protocol distinctions. This AUD concerns **private representations**, not making Collection behavior uniform.
- D261's R2-G2 architecture is selected but its **exact public FFI R2 API is not normatively published**. No new FFI or ByteRegion public mechanisms are ratified here.
