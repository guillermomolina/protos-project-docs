## Published implementation

1. `--allow-network` is explicit, default-denied initial-RootActor host Network authority for SOURCE file, `-e`, REPL, `debug`, and root-package MODULE `run` entry. It does **not** grant Resolver, Filesystem, inspection, other Tools or children ambient authority.
2. `--service=<binding>` independently selects existing D225-B1 RootActor message-service bootstrap for direct SOURCE or exported package MODULE. Service selection grants no Network on its own.
3. Process/RootActor lifecycle handling distinguishes a normally stopped RootActor from Process-level failure. Hosted service ownership and package/materialization resource scopes remain live until termination.
4. CLI help, guides and the RootActor example were updated. Java regressions cover option scoping, SOURCE bootstrap/stop, MODULE export versus private bindings, logical package execution and resource custody.
5. A real executable-level Python smoke test with a Protos HTTP service fixture exercises default-denial, loopback TCP, two HTTP/1.1 responses and service persistence: [smoke script](https://github.com/guillermomolina/protos/blob/398e6cb7478b0d7735ffcb6787d43c723cc32937/scripts/i154-cli-service-http-smoke.py), [guest fixture](https://github.com/guillermomolina/protos/blob/398e6cb7478b0d7735ffcb6787d43c723cc32937/src/test/resources/i154/cli-http-service.protos).

## Boundaries and residual verification

- The **real executable HTTP smoke is a direct SOURCE service**. The MODULE `protos run --service=...` path and external-package custody are covered by Java integration tests, but a **separate real Native `protos run` HTTP acceptance execution** was not reported. Do not represent the SOURCE smoke as a Native MODULE smoke; the latter remains a specific acceptance-evidence gap in I154/#1076.
- The smoke terminates the child process explicitly; it does **not** prove graceful HTTP draining on SIGINT. D247-C did not promise that behavior.
- This change implements only D247-C. Independent Filesystem and Resolver permissions remain owned by D248/#1074 and D249/#1075; no implicit grant or approval is inferred.
- No public release, Git tag, asset publication or native-distribution release is claimed by the implementation `-SNAPSHOT` bump.
