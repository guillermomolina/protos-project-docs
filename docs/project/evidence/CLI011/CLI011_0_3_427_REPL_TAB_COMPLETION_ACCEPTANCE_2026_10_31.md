## Implemented, bounded behavior

- `ProtosReplJLineCompleter` is the interactive editing adapter. The `streamRepl` non-terminal branch remains separate; TAB does not introduce shell-level completion for the external `protos` command.
- `ProtosReplCompletion` and `ProtosReplSourceCompletion` combine exact-session live lexical binding names, current-cursor parser/lexer-backed static proofs, and REPL meta-command candidates (`:help`, `:quit`, `:exit` only in command context). Incomplete or ambiguous source can decline completion rather than asserting unsupported knowledge.
- `ProtosActivation.lexicalBindingNamesForRuntime()` enumerates current local authority and the genuine captured lexical-parent chain, deduplicated nearest-first, using names-only APIs. No guest values, delegated members, guessed imports, receiver evaluation, or deferred-Context materialization are necessary for a TAB query.
- `ProtosPolyglotProcessContext` uses a private `persistentRootActorGate` around persistent RootActor evaluation and an on-demand `tryLock` for name observation, together with entered Process Context and lifecycle/identity checks. Contended, foreign, closed or otherwise unavailable observation returns no live names. This proves the **standalone REPL path**, not a new generic guarantee for every embedding entry or message-service RootActor execution mode.
- Cursor-in-middle replacement, nested expression contexts, Unicode/NFC boundaries and multiline input are handled under the established source and editing authorities. Existing history, paste, Ctrl-C, Ctrl-D and streamed input remain independent of discovery.
- REPL help and [CLI guide](https://github.com/guillermomolina/protos/blob/b50e256e0f48a20a19a0731116b131871fe2a585/docs/guide/tools/cli.md) now describe available TAB candidate categories and conservative limitations.

## Authority, exclusions and closure

D227-A1 revised authorizes read-only, names-only, on-demand observations and parser-authoritative completion as **interactive-tool behavior**, not new Protos language semantics. It excludes dynamic receiver/member discovery, module import or arbitrary guest execution for candidate generation, workspace indexing, LSP server startup and external shell completion. The approved policy allows conservative refusal on invalid/incomplete buffers. The historical [D227 source audit](../D227/D227_A1_OWNER_APPROVAL_AND_SOURCE_AUDIT_2026_10_31.md) remains an unchanged pre-implementation decision snapshot.
