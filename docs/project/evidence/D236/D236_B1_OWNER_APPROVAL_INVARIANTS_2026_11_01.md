**Why not edit `init` alone?** `CALLABLES.md` defines inherited standard `Object.call`: it creates the child of invoked receiver, then sends ordinary `init`, ignores `init`'s normal return, returns the original fresh child; the parent is immutable. Therefore `Range.init` returning `InvertedRange(...)` cannot deliver B1. The existing ordinary local `call` factory specialization (Array/Map/etc.) is the appropriate Protos-first mechanism. `EXECUTION_AND_CONTROL.md`'s `super.call` preserves the receiver and selects `Object.call` after canonical Range as methodHome. No host special case.

## Comparison, future cost, and rejected approaches

- Primary precedents: [Python `range`](https://docs.python.org/3/library/stdtypes.html#ranges), [Ruby `Range`](https://ruby-doc.org/3.4/Range.html), [Rust `Range`](https://doc.rust-lang.org/std/ops/struct.Range.html), [Kotlin ranges](https://kotlinlang.org/docs/ranges.html), [Swift `stride`](https://developer.apple.com/documentation/swift/stride%28from%3Ato%3Aby%3A%29), [GNU Smalltalk](https://www.gnu.org/software/smalltalk/manual/gst.html), [Lua 5.4 numeric `for`](https://www.lua.org/manual/5.4/manual.html#3.3.5), [Go specification](https://go.dev/ref/spec). Most require explicit signed step/direction or produce empty wrong-bound ranges; B1 is an intentional Protos result-prototype normalization choice, supported by Protos's existing extensible `call` mechanism rather than a universal precedent.
- A retains strict Errors but fails approved direct-call convenience and would force a later compatibility break; B2 facade changes public identity and modules; C only half-normalizes; D separate factory preserves compatibility but does not satisfy the direct-call contract; E host/object-intrinsic exemption violates no-pets and source-first principles without measured benefit.
- Risk: new legitimate opposite-bound construction can hide an argument-order bug previously detected by Error; direct prototype reflection/inherited `call` expectations break. Approval explicitly accepts these tradeoffs. Extra frozen source Closure/factory dispatch may have runtime or bootstrap cost; **not measured**.
