## Trust provenance limits

`Trust.anchors([...])` uses explicitly supplied DER anchors. `Trust.javaCacerts()` only reads the exact `java.home/lib/security/cacerts` path if an explicit `java.home` is available: the native default may have no such property and correctly returns `TRUST_MATERIAL_UNAVAILABLE`; it never falls back to ambient `javax.net.ssl.trustStore`, `jssecacerts`, default `SSLContext` or the OS. The tests prove controlled file provenance and runtime re-read in the test environment; they do **not** prove a native distribution supplies its own portable CA bundle or tracks live OS distrust updates. Likewise, successful fixture-driven in-memory Native TLS peer integration is not a public Internet CA-chain interoperability certification.
