## Native build cutover

The Maven `native` profile now contains the PLAT045-scoped build argument:

~~~text
-Dtruffle.UseFallbackRuntime=true
~~~

The setting is located inside the Native profile's Native Image build arguments.
The ordinary JVM/Surefire runtime plane is not converted to fallback mode.

Published contract represented by the code:

~~~text

~~~

## Native regression cutover

`build/native/test-native.sh` no longer treats successful guest Tier-2 compilation
as the selected Native-mode admission criterion.

The old forced-JIT log/source are replaced by an interpreter-only probe that:

- exercises ordinary guest execution through both generated Bytecode DSL root roles;
- requires the fallback-runtime warning marker;
- records explicit PLAT045 guest-JIT-unavailable policy;
- fails if any successful guest compilation is observed;
- fails on any optimization failure;
- fails on any `FrameWithoutBoxing` materialization failure; and
- fails on any compilation/internal failure.

The published markers include:

~~~text
NATIVE_INTERPRETER_ONLY_STATUS=
NATIVE_FALLBACK_RUNTIME_MARKERS=
NATIVE_GUEST_JIT_POLICY=UNSUPPORTED_UPSTREAM_ORACLE_GRAAL_14579

OPT_FAILED=

COMPILATION_FAILURES=
~~~
