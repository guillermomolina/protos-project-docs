## Source-backed public APIs and private native boundary

- [`protos/lib/core/filesystem/Open.protos`](https://github.com/guillermomolina/protos/blob/07406c7e4e51c627035256c0cba3c4bd2b7f433f/protos/lib/core/filesystem/Open.protos) defines the source Closure `filesystem.open(path, read: true, write: false, create: false, createNew: false, truncate: false)`. [`ProtosCoreBootstrap`](https://github.com/guillermomolina/protos/blob/07406c7e4e51c627035256c0cba3c4bd2b7f433f/src/main/java/com/guillermomolina/protos/execution/host/embedding/ProtosCoreBootstrap.java) loads it once as a private template. [`ProtosPrelude`](https://github.com/guillermomolina/protos/blob/07406c7e4e51c627035256c0cba3c4bd2b7f433f/src/main/java/com/guillermomolina/protos/runtime/ProtosPrelude.java) retains it for runtime binding; [`ProtosStandardFilesystemProtocol`](https://github.com/guillermomolina/protos/blob/07406c7e4e51c627035256c0cba3c4bd2b7f433f/src/main/java/com/guillermomolina/protos/execution/protocols/io/ProtosStandardFilesystemProtocol.java) binds the selected receiver for each provisioned capability. [`ProtosFilesystemValue`](https://github.com/guillermomolina/protos/blob/07406c7e4e51c627035256c0cba3c4bd2b7f433f/src/main/java/com/guillermomolina/protos/runtime/io/ProtosFilesystemValue.java) holds that capability's one-time bound private open flow. The private frozen bridge delegates to the existing validator/flow, not a public options-object selector.
- [`protos/lib/core/network/Network.protos`](https://github.com/guillermomolina/protos/blob/07406c7e4e51c627035256c0cba3c4bd2b7f433f/protos/lib/core/network/Network.protos) declares source-backed `network.listenTcp(ipVersion:, address:, port:)`; all three arguments are required, with a bootstrap-private omission identity distinguishing missing fields from supplied `null`. [`ProtosStandardNetworkProtocol`](https://github.com/guillermomolina/protos/blob/07406c7e4e51c627035256c0cba3c4bd2b7f433f/src/main/java/com/guillermomolina/protos/execution/protocols/io/ProtosStandardNetworkProtocol.java) retains network authority and native admission through a private frozen bridge. `connectTcp` remains native.
- D237 association rejects unknown named labels and positional/named collisions as a generic pre-body `Error` without returning a Future. Correctly bound invalid options, missing network fields or invalid network values yield the established failed `Future<InvalidIOArgument>`; no backend effect is expected for rejected requests.
- No general Java kwargs association, global conversion of option objects, new public bridge, or alternate public selector was introduced. Existing D013 method extraction and D239/Object.call rules are used rather than special-cased.
