## Generated plain-root boundary

The regenerated `MiniPlainRootGen.java` contains:

```java
@Override
public Object execute(VirtualFrame frame) {
    return continueAt(bytecode, 0, stackBase, (FrameWithoutBoxing) frame);
}

private Object continueAt(
        AbstractBytecodeNode bc,
        long bci,
        long sp,
        FrameWithoutBoxing frame) {
    boolean wasCompiled = CompilerDirectives.inCompiledCode();
    long state = ((sp & 0xFFFFFFFFL) << 32) | (bci & 0xFFFFFFFFL);
    while (true) {
        state = bc.continueAt(this, frame, state);
        if ((int) state == 0xFFFFFFFF) {
            break;
        } else {
            CompilerDirectives.transferToInterpreterAndInvalidate();
            AbstractBytecodeNode oldBytecode = bc;
            bc = this.bytecode;
            state = oldBytecode.transition(bc, state, wasCompiled);
            wasCompiled = false;
        }
    }
    return FRAMES.uncheckedGetObject(frame, ((int) (state >>> 32)));
}
```
