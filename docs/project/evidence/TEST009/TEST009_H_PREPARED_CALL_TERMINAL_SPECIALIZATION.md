## Product change

The published commit replaces the generic terminal Bytecode DSL operations:

~~~text
CompleteClosureCall.perform(PreparedClosureCall)
FinishClosureCall.perform(PreparedClosureCall, Object)
~~~

with concrete Truffle specializations for the closed prepared-call leaf set:

~~~text
OrdinarySourceCall
NativeCall
ImmediateResultCall
ModuleInitializationCall
~~~

The change is applied in both generated Bytecode interpreter declarations:

~~~text
src/main/java/com/guillermomolina/protos/execution/ProtosBytecodeRootNode.java
src/main/java/com/guillermomolina/protos/execution/ProtosSemanticBytecodeRootNode.java
~~~

Lifecycle behavior remains owned by the prepared-call representations. No new
`@TruffleBoundary`, `@CompilationFinal`, cache, assumption, representation
flag, enum discriminator, or universal carrier was introduced.

Direct Java callers that previously called the Bytecode operation with an
interface-typed `PreparedClosureCall` now call the representation's existing
`finish` contract directly rather than preserving a generic specialization
solely for Java test/helper convenience.
