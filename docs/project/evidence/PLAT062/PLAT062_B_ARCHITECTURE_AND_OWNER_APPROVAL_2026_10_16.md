## Distinguish measured and unmeasured

The owner independently captured GraalPy `__graalpython__.dis(..., False)` for `def identity(value): return value; identity(1)`, reporting 12 module instructions / 5 function instructions. An earlier Protos source diagnostic reported 434 instructions in a distinct source/root/topology with `run`; those numbers **cannot be divided into a valid cross-language performance or current-head compression ratio**. This project record introduces **no new disassembly run, no optimized Graal IR, no exact peer workload match, no measurements, no local builds or tests**. ## Adversarial falsification matrix for the implementing I-family item

1. Fresh Closure objects sharing source definition remain `!==` by guest identity; captured mutable lexical cells update by reference.
2. Argument expression mutates the receiver's `call`; **selection after evaluating arguments** must select the new method, without duplicate effects.
3. Context/local/ancestor remove/recreate/shadow/freeze/close reflects D179; no cached stale resolution.
4. Default expressions evaluate on invocation in live activation, including receiver/context/prior parameters; explicit `null` suppresses default, extra args/rest preserve D203.
5. Same call site: **generic→eligible→generic→eligible**, plus method override removal/invalidation, polymorphic and megamorphic cache churn. Negative input must not irreversibly evict a positive specialization.
6. Receiver-bound method, extracted method, methodHome and `super` semantics intact.
7. Nonlocal `ReturnHome` valid/invalid/escaped/Task-crossing results unchanged.
8. Generic call to body/default that suspends; resume exactly once; no earlier argument replay and no bogus “proven no suspension.”
9. Throw in arguments, lookup, defaults, body and finally; cancellation and cleanup precedence unchanged.
10. Native/foreign/host, uncached, multiple entered Contexts and AOT/native reachability remain safe and pay-as-you-grow.
11. NORMAL/DEBUG source/RootTag/CallTag/SourceSection/BCI, reparse and complete root-group/proxy signatures stay correct.
12. Actual operation-count improvement for a **valid, comparable, proven-non-suspending** dynamic call must be demonstrated; generated PE, machine code, steady timings separately assessed, not inferred.
