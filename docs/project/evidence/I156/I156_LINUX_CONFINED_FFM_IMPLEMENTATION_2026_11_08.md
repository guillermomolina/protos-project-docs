# I156 — Linux confined Filesystem via Java 25 FFM (2026-11-08)

Issue: [I156 #1083](https://github.com/guillermomolina/protos/issues/1083). Architecture: [PLAT072 #1082](https://github.com/guillermomolina/protos/issues/1082) amended by [PLAT073-C #1084](https://github.com/guillermomolina/protos/issues/1084).

A Linux x86_64 Filesystem backend using pinned directory descriptors, `openat2` resolution, Landlock and Java 25 FFM libc `syscall` downcalls replaces the former pathname-confinement backend. It uses grant-scoped restricted workers, retains File descriptor identity and asynchronous I/O/cancellation rules, refuses unsupported hosts without weaker fallback, and ships no Protos-specific JNI/C library. Primary implementation files are under `src/main/java/com/guillermomolina/protos/execution/host/io/ProtosLinuxConfined*`; File/Byte I/O flows, Native Image metadata and smoke harnesses also changed.
