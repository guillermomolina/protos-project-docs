## Extracted Native gate cutover

The obsolete:

~~~text
validate_forced_guest_jit(...)
~~~

path is removed.

The extracted Native validator now uses:

~~~text
validate_interpreter_only_guest_runtime(...)
~~~

The probe executes ordinary extracted Native guest code without requesting guest
compilation. It exercises both generated interpreter roles through the maintained
bounded workload and requires Truffle's own fallback-runtime warning as positive
runtime-selection evidence.

The selected policy is retained explicitly as:

~~~text
NATIVE_GUEST_JIT_POLICY=UNSUPPORTED_UPSTREAM_ORACLE_GRAAL_14579
~~~

## Fail-closed classification

The implementation counts:

~~~text
fallback_markers
opt_done
opt_failed
frame_failures
compilation_failures
~~~

and admits only:

~~~text
fallback_markers >= 1
opt_done = 0
opt_failed = 0
frame_failures = 0
compilation_failures = 0
~~~

Therefore the extracted distribution fails closed if:

- fallback runtime selection evidence is absent;
- guest compilation unexpectedly succeeds;
- an optimization failure occurs;
- the FrameWithoutBoxing materialization defect reappears; or
- a compilation/internal failure is reported.

The obsolete release-admission requirements:

~~~text
HELPER_BYTECODE_ROOT_TIER2>=1
SEMANTIC_BYTECODE_ROOT_TIER2>=1
~~~

are removed for the PLAT045 fallback mode.

The stale success markers:

~~~text
NATIVE_DIST_FORCED_GUEST_JIT_CHECK=PASS
NATIVE_DIST_HELPER_BYTECODE_ROOT_TIER2_CHECK=PASS
NATIVE_DIST_SEMANTIC_BYTECODE_ROOT_TIER2_CHECK=PASS
~~~

are replaced by truthful PLAT045 markers including:

