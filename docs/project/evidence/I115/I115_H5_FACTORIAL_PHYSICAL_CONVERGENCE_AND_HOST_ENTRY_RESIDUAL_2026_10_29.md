## Publication and validation provenance

- The owner reports clean `git diff --check`, and local `make test` and `make check` **PASS**. These are owner-reported results; the documentation agent did not execute these commands.
- The published commit removes generic global resolution from the installed `ReadGlobal` fast path (cached resolved value), replaces experimental `run()` terminal dispatch with a cached `RootCallTarget` plus `DirectCallNode`, uses the same reduced static unary ABI for `run()` and recursive `factorial()`, and skips return carrier materialization on experimental callee roots. The lowerer admits the experimental terminal operator only for registered eligible recursive integer bindings; nonrecursive and other callable cases retain the ordinary call operator.
- The reduced fast path deliberately freezes the resolved global and call target and bypasses receiver/Context/`Object.call` revalidation, caller/Prelude/Task/ReturnHome transport, suspension/control transfer and normal guest result projection. These are **experimental semantic deviations**, not accepted language or platform changes.
- The attached cold-capture manifests independently identify product revision `5216be7ca17dfcaa320c56102bb61b488d89c139`, identical source-state SHA-256 `369c6c5168bfe9c84d7e13483bde79bdea4222e1c2c3c8996574c291f4ce34ba`, `capture_valid=true`, and `correctness.result=PASS`, actual `2432902008176640000` (factorial 20), for **both** requested tiers.

## Guest-root physical convergence

All counts are graph nodes in `1: After TruffleTier`. The older Protos archive contains **only the run root**, not the old factorial root or old host root.

| Root | Tier | Earlier Protos | H5 Protos | GraalPy |
| --- | ---: | ---: | ---: | ---: |
| `run()` | 1 | 355 | **129** | 161 |
| `run()` | 2 | 453 | **250** | 407 |
| `factorial()` | 1 | unavailable | **161** | 216 |
| `factorial()` | 2 | unavailable | **298** | 568 |

The `run()` reduction versus the earlier Protos artifact is **226 nodes (63.7%)** at Tier 1 and **203 nodes (44.8%)** at Tier 2. H5 guest-root node counts are below the matched GraalPy graphs, but the reduction cannot be assigned separately to each of the three H5 cuts without an ablation.

**Later pipeline stage, `5: After low tier`:**

| Root | Tier 1 Protos / GraalPy | Tier 2 Protos / GraalPy |
| --- | ---: | ---: |
| `run()` | **202 / 272** | **376 / 553** |
| `factorial()` | **349 / 477** | **724 / 1012** |

The gain persists past TruffleTier. In H5 `run()`, T1 `IfNode=4`, `FixedGuardNode=0`, `InvokeWithExceptionNode=2`; T2 `IfNode=0`, `FixedGuardNode=0`, `InvokeWithExceptionNode=1`. Earlier Protos `run()` had T1 `15/11/6` and T2 `8/12/5` for these respective classes. Tier 2 inlines multiple recursive levels, with a residual cutoff, in both Protos and GraalPy.

**Limit:** the prior archive does not include a pre-H5 `factorial()` or host-entry BGV, so there is no complete paired whole-program pre/post attribution. Independent call-target node counts must not be summed into a purported runtime cost: inlining duplicates guest code inside other compiled graphs.

## Remaining physical gap: host entry

The `org.graalvm.polyglot.Value<ProtosHostExecutableClosure>.execute` graph remains much larger than GraalPy's `org.graalvm.polyglot.Value<PFunction>.execute` graph:

| Host entry, After TruffleTier | Protos H5 | GraalPy |
| --- | ---: | ---: |
| Tier 1 | **2,319** | **370** |
| Tier 2 | **2,678** | **675** |

Tier 1 Protos host entry has **172 IfNode**, **86 InstanceOfNode**, **87 FixedGuardNode**, **104 LoadFieldNode**, against GraalPy **9, 2, 16, 15**, respectively. The call tree has **three distinct calls to `run()`** before inlining on the Protos host entry, versus **one** on the GraalPy host entry. Tier 2 inlines these repeated guest call paths in the host compilation; this is a concrete candidate for code-growth reduction, **not** proof that the three sites have identical semantics or can be removed without examining the Java branches. `ProtosEmbeddedProcess` error/entry checks remain visible among host graph invokes.

**Next research-only slice:** inspect the source-to-graph attribution of the three `run()` host call sites and the 172/168 host `IfNode` (Tier 1/Tier 2), `InstanceOf`, guards and field loads. Compare directly with GraalPy `Value<PFunction>.execute` and its actual call entry. Propose the smallest physical convergence cut **in the host entry only**, preserving H5 `run()`/`factorial()` graph wins, the reduced static ABI, target caching and unprojected return.
