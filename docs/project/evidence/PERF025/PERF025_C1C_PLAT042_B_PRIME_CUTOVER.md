## Published topology

The published product now has two generated Bytecode interpreter roles:

~~~text
ProtosSemanticBytecodeRootNode
    = tagged semantic source interpreter

ProtosBytecodeRootNode
    = untagged structured-dispatch / C-prime interpreter
~~~

`CanonicalToBytecodeLowerer` now lowers top-level/module/Closure source roots
directly into `ProtosSemanticBytecodeRootNode`.

The former semantic-wrapper-to-helper path has been removed.

~~~text
UNIVERSAL_SEMANTIC_WRAPPER=REMOVED
ORDINARY_SOURCE_CLOSURE_CALLTARGET_COUNT=1
~~~

Lexically nested semantic Closures remain in the same semantic
`BytecodeRootNodes` generation as their lexical owners, preserving the
PERF013 same-generation materialized-local path.

Object-construction bodies remain inline, non-root and non-lexical as established
by C1b.

## Structured owner

The large structured dispatcher now lives in:

`src/main/java/com/guillermomolina/protos/execution/ProtosStructuredDispatchLowerer.java`

and targets the untagged `ProtosBytecodeRootNodeGen.Builder`.

Semantic source lowering performs only the structured/non-structured choice.

For a structured prepared call:

~~~text
semantic source root
    -> ProtosSemanticBytecodeRootNode.EnterNestedStructuredDispatch
    -> Context-stable ProtosTaskCPrimeEntryExecution target
    -> untagged structured dispatcher
~~~

The semantic entry has a cached `DirectCallNode` specialization for the stable
Context target and an `IndirectCallNode` fallback.

The existing PLAT014 continuation/error/control composition remains intact.

~~~text
STRUCTURED_CPRIME_OWNER=UNTAGGED
STRUCTURED_ONLY_HELPER_BOUNDARY=YES
STRUCTURED_DIRECT_CALL_SPECIALIZATION=YES
NEW_CONTINUATION_KIND=NO
REPLAY=NO
~~~

## Operation ownership

The semantic source interpreter declares the required source-surface operation
wrappers and delegates their implementations to the existing static operation
implementations in `ProtosBytecodeRootNode`.

This avoids duplicating semantic implementation logic while allowing two
differently configured generated Bytecode interpreters.

`OperationProxy` was not used because the current operation classes are not
Node-based proxyable classes.

Unused source-side operation definitions may remain temporarily in the untagged
interpreter, as explicitly permitted by PLAT042's low-risk migration authority.

## Bounded performance evidence

The 0.3.133 product CHANGELOG records the bounded JVM comparison against the
published C1a+C1b baseline:

~~~text
BASELINE=595d547b2e9714a185a3cfceadf74565229f43e7

ORDINARY=-46%

RETAINED_CLOSURE_CALL=-43%
~~~

All three measured classes improved, including the workload that crosses the
new structured helper boundary.

This matters because PLAT042's principal downside was the possibility that the
structured-only helper CallTarget would materially regress structured paths.
The bounded evidence falsifies that concern for the measured workload set.

## Residual stack/carrier evidence

The BUG008-specific carrier remains present:

~~~text
GUEST_CALL_STACK_SIZE_BYTES=64 MiB
DEDICATED_GUEST_CARRIER=STILL_PRESENT
SESSION_SERIALIZATION=PRESERVED
BUG008=#681 CLOSED_DO_NOT_REOPEN
~~~

C1c removed the old universal semantic-wrapper source CallTarget.

The remaining retained recursion drivers nevertheless still recurse through:

~~~text
repeat(count, operation)
    -> (count > 0).ifTrue(...)
    -> structured-dispatch helper root
    -> callback Closure
    -> recursive repeat(...)
~~~

at every recursion level.

The current benchmark contract intentionally retains those checked-in
10,000-deep recursive repetition shapes.

The 0.3.133 CHANGELOG records that this shape still needs a large fixed stack,
approximately 32 MiB in interpreter execution.

Therefore:

~~~text
OLD_UNIVERSAL_SOURCE_STACK_AMPLIFICATION=REMOVED
RESIDUAL_STRUCTURED_RECURSION_STACK_AMPLIFICATION=ESTABLISHED

CARRIER_RETIREMENT_GATE=NOT_PASSED
64_MIB_STACK=STILL_PRESENT
CARRIER_HANDOFF=STILL_PRESENT
~~~

This evidence does not authorize changing the benchmark recursion depth or
replacing the 64 MiB value with the observed 32 MiB threshold without a
portable safety argument.
