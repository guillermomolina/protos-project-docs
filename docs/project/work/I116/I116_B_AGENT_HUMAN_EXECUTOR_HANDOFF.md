## Exact remaining gap and bounded objective

I116-A already proves **optimized** constant-return and scalar-local bodies with the in-process Truffle `DebuggerSession`, both before lowering and after late attach; it also proves DEFAULT budget/oracles, tags and real lexical scopes. Existing DAP TCP tests prove real protocol, breakpoint/stack/scopes/next for **ordinary** non-optimized source, and public CLI readiness. The missing cross-product is a **real DAP/TCP client** observing optimized surviving statements and scopes in a compiled Protos program, without resurrecting eliminated semantic operations. This is an evidence/acceptance gap, **not** a demonstrated production-code defect.

**I116-B acceptance:** Add a real DAP wire test for `run: () => { 1 }` with a breakpoint on the constant-return statement and intact source/stack; add a real DAP wire test for `run: () => { first: 7; second: first; second }` with breakpoints on three source statements, plus scopes/values (absent/7 and 7/7), and no fabricated callback frame. Reuse existing test TCP harness rather than cloning a DAP protocol implementation. Cover a late DAP client attach to an already parsed/prepared root only if the same Engine DAP endpoint supports that sequence without a new host or a fabricated guest execution mode. Preserve existing in-process late-attach coverage regardless.
