**File 1 — NEW `protos/lib/http/internal/MessageBody.protos`.** Add the complete Adaptive Public License `//` header following `MessageHead.protos`, plus `//!` module documentation labelling it strictly internal/unpublished. Exactly three top-level private module selectors are allowed in this batch:

- `requestBodyFramer(head, limits)`: captures framing (`NONE`, `CONTENT_LENGTH`, `CHUNKED`) and content length from LIB025-A's accepted head, plus independently bounded `maxChunkLineBytes`, `maxTrailerBytes`, `maxTrailerFields`, `maxRequestBodyBytes`. Return one stateful object with `feed(bytes, offset, length, maxContentBytes)`, `endOfInput()`, and `state()`. `state()` reports `OPEN`, `COMPLETE`, or `REJECTED`; pure `feed` result is `{state, consumed, content, failure}`, where `state` is `NEED_MORE`, `CONTENT`, `COMPLETE`, or `REJECTED`. `content` is a fresh Bytes only for `CONTENT`, and `failure` is only for `REJECTED`, as `{kind, status}` with `malformedRequest/400` or `requestLimit/413`.
- `encodeResponseChunk(payload)`: pure Bytes encoder for one non-empty payload. Snapshot the payload before encoding: lowercase/uppercase hexadecimal chunk-size (either is valid), CRLF, exact original payload octets, CRLF. Reject empty payload as a private caller mistake, signaling ordinary `Error()`.
- `finalResponseChunk()`: answers fresh Bytes containing exactly `0\r\n\r\n`; no I/O.

Implement **NONE** without consuming body bytes; **CONTENT_LENGTH** with exact remaining-octet tracking, no consumption beyond the message boundary, no premature EOF acceptance; and **CHUNKED** incrementally over arbitrarily fragmented size lines/extensions, data, per-chunk CRLF, zero-size last chunk, trailers and terminating CRLF. Stop `feed` immediately after it has non-empty content to return, or when the message completes/fails; do not parse future bytes after a returned content slice, so late framing errors cannot jump ahead of delivered content. Enforce output budget `maxContentBytes` and report exact `consumed` within the caller's slice. Use immutable logical copies for returned content; never mutate the source Bytes. Reject invalid bounds (`offset`, `length`, budget) before changing framer state, using `length > bytes.size() - offset` after bounds guards. Zero-length feeds are valid. `endOfInput()` is the pure explicit physical-EOF notification: if the message has not reached its logical end, reject with fresh `malformedRequest/400`; it never performs I/O. Do not silently treat a fixed/chunked truncated body as successful EOF. Never allocate an unbounded body buffer; buffer only bounded framing lines.

External wire syntax (RFC 9112 §7.1, provided here so the agent does not browse): `chunked-body = *chunk last-chunk trailer-section CRLF`; `chunk = chunk-size [chunk-ext] CRLF chunk-data CRLF`; `chunk-size = 1*HEXDIG`; `last-chunk = 1*("0") [chunk-ext] CRLF`; `chunk-ext = *(BWS ";" BWS token [BWS "=" BWS (token / quoted-string)])`; `trailer-section = *(field-line CRLF)`; `field-line = field-name ":" OWS field-value OWS`. Reject lone LF, invalid CR placement, missing post-data CRLF, invalid extension tokens/quoted-string escaping, folded/invalid trailer lines, malformed trailer terminator and numeric overflow. Chunk extensions are parsed/ignored (not returned). No trailer is exposed to handlers. Trailers use token names, allowed HTTP field-value octets and independent byte/field limits; count the terminating trailer CRLF toward `maxTrailerBytes`. Cumulative decoded body octets (not transfer framing) respect `maxRequestBodyBytes`, including the exact boundary. Protos Integers are semantically unbounded; check the driver's signed-64 representability of parsed hex sizes explicitly, using overflow-safe arithmetic (no Float conversion, no arbitrary BigInteger Java dependency). Exceeding supported integer representation is malformed (400); a representable cumulative decoded content length exceeding `maxRequestBodyBytes` is requestLimit (413). On error, terminalize the private framer and never create a public HttpError prototype in this batch.
