### Structural grammar and precedence (all approved)

- FOR and IN remain lexer IDENTIFIER spellings except their specific contextual use; no reserved FOR or IN token. No general infix in operator. Recognize **only** an ungrouped, bare primary name for in ordinary call-suffix position with a same-continuing-logical-line braced body and one of the EXACT shapes.
- Generic shape inside parentheses: simple bare ordinary identifier binder, separate identifier token whose lexeme is in, and one complete ordinary nonspread expression. No commas at that level, rest/default/destructuring binder, missing expression or second binder. Ordinary newlines within enclosing parentheses follow existing multiline argument-layout rules.

- Body must be immediately attached to the completed closing parenthesis in the continuing logical token sequence. ### Operational meaning (all approved)

- Generic: evaluate expression ONCE and normally send its selected each with exactly ONE freshly created ordinary Closure value. Each receiver owns result, callbacks and validation. Standard Array.each returns the original Array and uses shallow snapshot; standard Range.each returns null; standard Map/IdentityMap.each sends callback(key,value) and returns the original Map, so the one-formal for(key in map) receives **the key only** and ignores surplus value by ordinary flexible Closure parameter-binding semantics; custom each may return any value, signal, suspend or invoke callback its own number of times. To receive both Map arguments, explicit map.each((key,value)=>{...}) stays available. No Map-pair convenience or universal iteration result.
- Numeric: evaluate ordinary lexical identifier Range at source site (not a privileged Core identity, and no canonical eligibility guard). A user-local Range shadow is allowed and retains exactly the behavior of explicit Range(a,b). Call the result's normal each (3 header positions) or eachStep (4 header positions). Never use the sign of step to select Range vs InvertedRange: the shipped D236-B1 source-backed factory selects according to original bounds. D236 canonical Range(10,0) returns InvertedRange(10,0), Range(0,10) returns Range(0,10), Range(5,5) stays ascending empty Range. Both ranges have first bound inclusive, second exclusive; numbers are genuinely unbounded Integers. eachStep validates positive step for actual Range, negative for actual InvertedRange, even when empty; zero, noninteger or opposite sign Error. Do not normalize step sign or include the stop bound.

No upfront evaluation of (start,stop,step) before constructing Range; old tentative D231 M1 header-staging was explicitly rejected.
