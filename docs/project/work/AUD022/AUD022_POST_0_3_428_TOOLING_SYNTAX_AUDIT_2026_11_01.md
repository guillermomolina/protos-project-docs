## Result and exact product delta

The published commit has exactly **nine changed paths**: seven existing Java JUnit test files, `pom.xml`, and root `CHANGELOG.md`; **304 insertions, 3 deletions**. It adds **eight regression tests**, fixes **two obsolete source-spelling assertions** inherited from I142, and changes **no production implementation, guest Library, language grammar, normative specification, debugger transport implementation, or VS Code extension**. The Maven version was bumped once, `0.3.436-SNAPSHOT` → `0.3.437-SNAPSHOT`, after successful behavioral validation; no tests were run after version/changelog finalization.

The user executed and reported PASS for each of the five AUD022 focal test batches: document symbols; real TCP DAP contextual return; Truffle debugger callback scope across generic/numeric/stepped `for`; mixed-syntax formatter; LSP completion and signature help. The first integrated `make check && make test` attempt passed `make check` but **failed** in the Java parallel lane (4591 tests, one failure, zero errors, four skipped): `ProtosTestToolFileSelectionMainAdoptionTest.everyExplicitSelectorMustMatchBeforeUnionFiltering`. Investigation against the exact baseline established that `protos/tools/test/Main.protos` had migrated to `for(filePath in filePaths)` and `for(directoryPath in directoryPaths)` while that test still asserted the former literal `.each` spellings. The two assertions were changed and its three-test focal class then passed. The user subsequently reported **`make test` PASS** for the final seven-test-file candidate. `git diff --check` was clean before and after metadata; the owner published `7ded55154dd8ee80eb54bc3dd29dfd438dbff6d3` to `main` with a clean post-push working tree. The assistant did not execute Maven or Make locally.

## Specification and architecture constraints

- [`spec/PROTOS_GRAMMAR.md`](https://github.com/guillermomolina/protos/blob/7ded55154dd8ee80eb54bc3dd29dfd438dbff6d3/spec/PROTOS_GRAMMAR.md): normative operator lowering, contextual `return` and three contextual `for` surface forms. The audit does not promote `for`, `in`, `return`, `Range`, or `InvertedRange` to reserved words.
- [`spec/semantics/VALUES_AND_COLLECTIONS.md`](https://github.com/guillermomolina/protos/blob/7ded55154dd8ee80eb54bc3dd29dfd438dbff6d3/spec/semantics/VALUES_AND_COLLECTIONS.md): directed Integer Range/InvertedRange and Integer bitwise messages. `each`/`eachStep` remain ordinary messages; `for` uses canonical desugaring.
- [`spec/semantics/EXECUTION_AND_CONTROL.md`](https://github.com/guillermomolina/protos/blob/7ded55154dd8ee80eb54bc3dd29dfd438dbff6d3/spec/semantics/EXECUTION_AND_CONTROL.md) and [`spec/semantics/CALLABLES.md`](https://github.com/guillermomolina/protos/blob/7ded55154dd8ee80eb54bc3dd29dfd438dbff6d3/spec/semantics/CALLABLES.md): closure-scoped binders and existing non-local return semantics; no duplicate loop evaluator or return-home machinery.

## Boundaries, follow-ups and closure

**Verdict:** KEEP the current parser, LSP, formatter, Truffle debugger and existing DAP architecture; reconcile only actual proof gaps. This audit did not propose a semantics-changing removal, a new parser, a new reserved token, a new source formatter or an additional language-level runtime node.

The Protos test changes and the one reproduced stale Test Tool test were resolved in the published `0.3.437-SNAPSHOT` commit. The independent extension defects/gates remain under [BUG002](https://github.com/guillermomolina/protos-vscode-extension/issues/4) and [CI002](https://github.com/guillermomolina/protos-vscode-extension/issues/5); they do **not** claim that the present unreleased Protos source has been accepted through a released VSIX. No transport-level contextual `for` DAP test was added; Truffle scope and real DAP contextual `return` are separate, honest evidence. This distinction is a bounded test-coverage limit, not a demonstrated regression and not a semantic design blocker.

**Validation provenance:** all focal, `make check`, and final `make test` PASS claims are human-executor reports in the AUD022 conversation; the first full-suite failure and its focal repair are retained rather than hidden. Maven tests were not run following the `pom.xml` and `CHANGELOG.md` edits. The modified source files retained their existing APL Part 5 notice; `LICENSE.TXT` was not modified.
