## Problem and corrected R1 diagnosis

I115 materially reduced the observed bare-\`identity(1)\` TOP_LEVEL After TruffleTier graph from **1,080 to 707** nodes (whole-root comparison); its reported \`InvokeClosureOneTail\` source ancestry remains approximately **125 inclusive nodes**, *not* 125 individually removable nodes. Existing physical evidence: [I115 residual post-mortem](../../evidence/I115/I115_382_TIER1_RESIDUAL_CONVERGENCE_AND_PLAT066_HANDOFF_2026_10_18.md).

R1 was incompletely investigated. Replacing one ordinary lookup with a boolean presence test and a series of admission guards **on every PIC hit** is not the same as letting the PIC preserve a previously selected method through invalidation.

## Owner-selected R1 implementation direction (not implemented)

**Goal:** cache/prove the **selected ordinary \`call\` slot** for each eligible direct specialization and use coherent invalidation rather than repeat full selection/admission on every hit. Preserve the existing one-operation terminal fusion, canonical \`Object.call\`, D013 and B5+.

1. **Post-operand selection.** The receiver and all supplied operands are already evaluated when the DSL call specialization chooses an entry. A \`call\` created/removed/replaced during argument evaluation must be visible **before invocation**. Misses must use the exact D013 general path; a non-Closure local \`call\` is an error, never silently skipped.
2. **Identity-keyed PIC:** install a receiver-specific guarantee that no own \`call\` shadows canonical \`Object.call\`, plus the canonical-root \`Object.call\` selection \`Assumption\`. Register invalidation on *that Closure's* local-selector authority for all resolution-changing mutations; separate plans/Context/ReturnHome as independent immutable or invalidatable facts. The hit should be guarded by receiver identity and valid compiled assumptions; **do not call \`admittedCachedInstance\` again solely to re-prove stable selection**.
3. **Definition-keyed PIC:** many distinct Closure instances share definition, plan and Context but **not mutable local slots**. A receiver-specific assumption does not generalize across them. Investigate a **shared structural discriminator** for the no-own-\`call\` state (akin to GraalRuby meta-class/shape identity) that changes on local \`call\` create/remove, leaving at most the necessary minimal discriminator check per new instance and allowing the same Context-owned target to be reused. Do not introduce classes or guest-visible \`call\` metadata. Evaluate whether a real existing authority/layout discriminator can serve without parallel semantic state; if not, document the minimal backed-by-authority representation or fall back safely. **A zero-guard claim for arbitrary mutable fresh instances is not established.**
4. **Mutation/invalidation protocol:** exhaustively inventory slot create, assign, remove, compose/copy/bind, frozen/closed behavior, authority promotion/replacement, canonical-root mutation and any class-special overrides. Guarantee no stale compiled direct path can execute after resolution changes, including publication order and applicable Truffle memory/ownership rules. Value assignment to a *present* local \`call\` changes the selected Closure and must keep direct-default admission rejected; it does not necessarily change the binary presence discriminator. Non-\`call\` assignments must not invalidate \`call\` unnecessarily.
5. **Separate eligibility facts:** ReturnHome, prepared plan/rematerialization, entered Context, cross-Context projection, and Task/suspension proofs are distinct obligations, **not implied** by \`call\` selection. Derive stable facts from immutable fields/validated plan metadata or add correctly scoped invalidation only where provably valid. Do not turn this into an unchecked universal direct call, transfer work into another DSL operation, move cost eagerly into every Closure allocation, or materialize unused capabilities.
6. **Specialization establishment only:** allow slow lookup/registry construction on a PIC miss/installation, preferably \`@TruffleBoundary\` for cold bookkeeping; reserve the hot graph for necessary structural guards, B5+ ABI preparation, and actual direct execution. No new \`@Operation\` and no modifications to the bodies of other DSL operations.
7. **Fallback:** polymorphic/megamorphic, nonstandard local \`call\`, native Closure, deferred plan, unknown Context or genuinely observable control semantics continue through the existing safe paths.

**Before (current conceptual hot hit):**
\`\`\`text
receiver/context/plan guards
  && admittedCachedInstance(closure, facts, projection)
       // local-call presence + ReturnHome + plan + projection each hit
  -> pack B5+ -> DirectCallNode
\`\`\`

**After (bounded mechanism target, subject to implementation proof):**
\`\`\`text
after evaluating all operands:
  receiver identity / definition+Context+template applicability
  && declared canonical-root call assumption valid
  && (identity: local-call selection assumption valid
      | definition: current-instance structural no-local-call discriminator matches)
  && other proven necessary eligibility facts
  -> pack same B5+ -> same DirectCallNode
  otherwise -> existing authoritative D013 dispatch
\`\`\`

## Required human-executed acceptance

- **Functional:** initial \`f.call\` absent; override set **during argument evaluation**; reassignment to a distinct Closure and to non-Closure; removal; re-creation; existing \`f.call\` on another instance of the **same definition**; fresh Closure on every iteration; shadowing during warmup and after JIT; frozen/closed; bound/extracted Closure; native Closure; cross-Context/DEBUG; true and unobservable ReturnHome; Task/UNKNOWN/suspended and deopt; B5+ exact caller.
- **Physical:** same bare source \`identity: (value) => { value }; identity(1)\`; inspect matched \`After TruffleTier\` BGV and source-position attribution (inclusive vs disjoint); inspect presence of \`hasLocalCallSlotForRuntime\`, authority \`contains\`, \`admittedCachedInstance\`, added allocation/guards, remaining caller B5+ and numeric conversions; **compare whole-root** results with I115 baseline rather than claim 125 nodes removable. Do not attribute \`callBoundary\` as waste automatically.
- **PAYG:** no per-Closure assumption/map/shape instance solely for closures never participating in a guarded direct PIC; no cold-path requirement that forces global state; no persistent new Task/Actor/Process/Context overhead.
- **Evidence status:** no Protos edit, no tests/benchmarks, no matching GraalRuby BGV or measured new PE savings under this decision record.
